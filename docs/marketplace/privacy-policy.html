Privacy Policy: KMP Translations Hub

Effective October 23, 2026.

This policy covers the KMP Translations Hub plugin for JetBrains IDEs, published by Khubaib Khan.

Summary

KMP Translations Hub does not collect, sell or share any personal data, and has no analytics, telemetry, crash reporting or advertising. The plugin has no servers of its own. It connects to the internet in two cases only: when you run Translate Changes with an online translation service, it sends the strings being translated to the service you chose; and when you run Sync with Translation Platform, it exchanges your strings with the platform you set up (Crowdin, Lokalise or POEditor). Nowhere else.

What the plugin does on your computer

  • Your project's strings. The plugin reads and edits the composeResources/values… XML files of the project you open, and reads its Kotlin files to find Res.string… uses (for navigation and the unused-key check). Nothing is uploaded, except as described under Translation services and Translation platforms.
  • translations.lock.json. When strings are first machine translated or synced, the plugin writes this file next to the composeResources folder. It holds short hashes of texts (not the texts themselves), which service or "human" wrote each translation, and, once you sync, the platform and project ID you synced with (such as crowdin:123456). It stays in your project; you decide whether to commit it.
  • Settings. Your chosen service, the language of the default values folder, the Claude and OpenAI model names and the optional MyMemory email are stored in the IDE's settings on your computer (kmp-translations-hub.xml), with a count of Translate Changes runs and whether the rating request was shown. The translation platform to sync with, a project ID for each platform and the Crowdin Enterprise organization are stored in the project's .idea folder (kmp-translations-hub.xml).
  • API keys. DeepL, Google Cloud, Anthropic and OpenAI keys, and Crowdin, Lokalise and POEditor tokens, are stored in the IDE's password safe (on macOS the Keychain by default, or KeePass, as set in the IDE), never in a settings or project file.
  • Apple translation helper. On macOS the plugin copies its small translationshub-apple program into the IDE's system folder and runs it to use Apple's on-device Translation framework.
  • Files you create. Imports read, and exports write, only the files and folders you pick.

Translation services

Strings are sent only when you start Translate Changes, only for the locales and strings it lists (missing or outdated ones), and only to the one service selected in the dialog. Before sending, placeholders such as %1$s, inline markup and escapes may be replaced by neutral tokens; they're restored when the translation comes back.

Each service handles what it receives under its own terms, and with your own key, under your agreement with it. In particular, MyMemory's terms say it stores submitted text long term and uses it to improve its services, so don't send strings you consider confidential (unreleased product names, for example) through MyMemory; Apple on-device translation keeps them on your Mac. The plugin never sends your API keys anywhere except to the service they belong to.

Translation platforms

Sync runs only when you start it in the Translations tab, with the platform set in Settings → Tools → KMP Translations Hub → Translation Platform, and only for the folder whose tab you're in. Depending on the options you tick, it uploads the default-language strings with their key names and XML comments, uploads translations made in the IDE, and downloads the platform's translations.

KMP Device Hub

"Run App in Selected Locale" passes the locale's language tag (for example de) to the KMP Device Hub plugin, if you have it installed, on your computer. KMP Device Hub's own policy covers what it does with your devices.

Licensing and purchases

If you start a trial or buy a Pro license, JetBrains handles it through JetBrains Marketplace and your JetBrains Account, under JetBrains' privacy policy. The plugin only asks the IDE whether a license is present and checks JetBrains' signature on it locally. It never sees your payment or account details.

Third parties

Apart from the translation service and translation platform you choose, the plugin sends nothing to third parties. "Start Free Trial", "Get KMP Device Hub" and the one-time rating request's "Rate it" open JetBrains' website in your browser.

Children

The plugin is a developer tool and isn't directed at children.

Changes

If this policy changes, the new version will be published with the plugin and on its JetBrains Marketplace page, with a new effective date.

Contact
